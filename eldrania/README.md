# Эльдрания: Сумрачные Врата

Оригинальная idle RPG для Telegram Mini App. 15 героев, 5 фракций, 60 этапов кампании (6 глав с боссами),
автобои, призыв с pity, прокачка (уровни, звёзды, экипировка), отряд из 5 героев с бонусами фракций,
idle-награды, ежедневные задания, магазин. Интерфейс на русском, mobile-first.

Backend: Python 3.12+, FastAPI, SQLite (стандартный `sqlite3`). Frontend: HTML/CSS/JS без сборки.

## Быстрый старт (Windows, PowerShell)

```powershell
cd eldrania
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env          # в .env оставьте DEV_MODE=1 для локальной проверки
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8765
```

Откройте http://127.0.0.1:8765 — игра создаст тестового игрока.
Второй тестовый профиль: `http://127.0.0.1:8765/?dev_user=2` (работает только при `DEV_MODE=1`).
Swagger (только в DEV_MODE): http://127.0.0.1:8765/docs

Тесты логики и БД (только стандартная библиотека): `python -m unittest discover -s tests -v`

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен бота (@BotFather), нужен для проверки подписи initData | пусто |
| `DEV_MODE` | `1` — вход без Telegram под тестовым профилем. **В production = 0** | `0` |
| `DB_PATH` | путь к SQLite | `./game.db` |
| `INITDATA_MAX_AGE` | срок годности initData, сек | `86400` |
| `IDLE_CAP_HOURS` | лимит накопления idle-наград | `12` |

Если `DEV_MODE=0` и нет валидной подписи Telegram, API отвечает 401. Тестовый вход в production невозможен.
После изменения схемы БД удалите `game.db` (миграций в MVP нет).

## Подключение к Telegram

1. Создайте бота в @BotFather (`/newbot`), скопируйте токен в `.env` → `BOT_TOKEN`.
2. Поднимите приложение на сервере с **HTTPS** (Telegram требует HTTPS). Для проверки с компьютера подойдёт туннель:
   `cloudflared tunnel --url http://127.0.0.1:8765` или `ngrok http 8765` — получите адрес вида `https://xxxx.trycloudflare.com`.
3. В production запускайте с `DEV_MODE=0` (reverse proxy Caddy/nginx + `uvicorn main:app --host 127.0.0.1 --port 8765`, **один процесс**).
4. В @BotFather: `/newapp` (или `/setmenubutton`) → укажите бота, название и HTTPS-адрес игры.
5. Откройте бота → кнопка меню → игра. Сервер проверяет подпись `initData` официальным алгоритмом HMAC-SHA256;
   `user_id` от клиента не принимается на веру.

## Архитектура

```
main.py        HTTP-слой FastAPI (маршруты, валидация, обработка ошибок)
auth.py        проверка Telegram initData, DEV_MODE
services.py    все операции с БД: призыв, бой, idle, прокачка, магазин (в транзакциях)
game_logic.py  формулы, симулятор боя, pity, расчёт idle (чистые функции)
game_data.py   герои, фракции, монстры, главы, магазин, задания — единый источник данных
models.py      схема SQLite   database.py  соединения и транзакции BEGIN IMMEDIATE
config.py      переменные окружения
static/        index.html, css/style.css, js/{api,ui,heroes,battle,screens,app}.js, assets/
tests/         unittest
```

Принципы:
- Клиент показывает только то, что вернул сервер: результат призыва, исход боя, награды, цены.
- Каждая операция выполняется в одной транзакции `BEGIN IMMEDIATE`; баланс защищён `CHECK (>= 0)` в БД.
- Повторные запросы: `request_id` для призыва и боя (повтор вернёт сохранённый результат без новой выдачи);
  idle — compare-and-swap по `last_idle_claim`; дар дня и задания — флаги в БД.
- Бой: сервер симулирует весь бой (характеристики, классы, навыки, энергия, щиты, яды, оглушения, критические
  удары, фракционные бонусы) и отдаёт лог; клиент лишь проигрывает его.

### API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/catalog` | статические данные (герои, фракции, главы, магазин, вероятности) |
| GET | `/api/state` | полное состояние игрока (создаёт игрока при первом входе) |
| POST | `/api/idle/claim` | забрать idle-награды |
| POST | `/api/summon` | `{count: 1\|10, currency: tickets\|gems, request_id}` |
| POST | `/api/heroes/{key}/levelup` · `/equip` · `/star` | прокачка |
| PUT | `/api/squad` | `{slots: [5 × key\|null]}` |
| GET | `/api/stage/{n}` | превью этапа (враги, сила, награды) |
| POST | `/api/battle` | `{stage, request_id}` → лог боя, награды, новое состояние |
| POST | `/api/gift/claim` · `/api/quests/{id}/claim` · `/api/shop/buy` · `/api/cosmetics/frame` | прочее |

### Экономика (кратко)
- Старт: 5 000 золота, 3 000 опыта, 600 самоцветов, 10 билетов, 3 стартовых героя, 1 час накопленного idle.
- Idle: `900 + 120·этап` золота/ч, `500 + 70·этап` опыта/ч, 4 самоцвета/ч, лимит 12 ч.
- Награда этапа: `120 + 40·n` золота, `80 + 25·n` опыта; первое прохождение ×2.5 + самоцветы (боссы: +билеты).
  После 40 побед за день награда за повторы ×0.25.
- Призыв: 1 билет или 150 самоцветов; ×10 за самоцветы — 1 350. Шансы: обычный 40%, редкий 45%, эпик 12.5%,
  легендарный 2.5%. Гарантия эпика каждые 10, легендарного на 50-м; мягкий pity с 36-го (+4% за призыв).
- Повтор героя → фрагменты (5/8/15/30), идут на звёзды (+15% статов, +8 к пределу уровня).
- Все числа задаются в `game_data.py` и `game_logic.py`.

## Замена портретов настоящими артами
Положите `static/assets/heroes/<key>.webp` (или `.png`/`.jpg`), например `alaric.webp`. Сервер сам добавит
`portrait_url` в каталог, код менять не нужно. Фоны глав: `static/assets/backgrounds/`.

## Будущие платежи (Telegram Stars)
Платежи **отключены**: премиум-товары в магазине показаны недоступными, `POST /api/shop/buy` отвечает 403.
План интеграции: сервер создаёт счёт (`createInvoiceLink`, валюта `XTR`) на фиксированный набор → клиент открывает
`Telegram.WebApp.openInvoice` → бот обрабатывает `pre_checkout_query` и `successful_payment` → выдача только после
подтверждения платежа ботом, `telegram_payment_charge_id` пишется в `events` с уникальным `idem_key`
(защита от двойной выдачи). Никаких случайных платных наград и вывода средств.

## Расширение
Новый герой — запись в `HEROES` (`game_data.py`). Новая глава — запись в `CHAPTERS` (+10 этапов к `MAX_STAGE` автоматически).
Задания — `QUESTS`. Гильдии, PvP, башня, события, таблица лидеров: добавляются отдельными таблицами в `models.py`
и модулями сервисов; сейчас в UI они помечены «Скоро».

## Чек-лист проверки (вручную)
- [ ] Проект запускается командой `python -m uvicorn main:app --reload --host 127.0.0.1 --port 8765`
- [ ] Создаётся тестовый игрок, открывается главный экран
- [ ] «Забрать награды» увеличивает золото/опыт/самоцветы; повторное нажатие — «нечего забирать»
- [ ] Призыв ×10 за билеты: анимация, результаты, новые герои в коллекции; повтор героя даёт фрагменты
- [ ] Окно «Вероятности призыва» открывается, счётчики pity растут
- [ ] Карточка героя → «Повысить» списывает золото/опыт; при нехватке кнопка заблокирована
- [ ] Отряд из 5 героев собирается, дубли невозможны, состав сохраняется после F5
- [ ] «Сражение»: бой проигрывается (атаки, числа урона, ультимейты, победа/поражение), награды начислены
- [ ] После первой победы открывается следующий этап; F5 не теряет прогресс
- [ ] Магазин: покупки за самоцветы работают, премиум-товары недоступны, дар дня — раз в сутки
- [ ] Через HTTPS в Telegram: игра открывается, имя игрока подтягивается из Telegram, `DEV_MODE=0`

## Известные ограничения MVP
Нет миграций БД; сервер рассчитан на один процесс; даты заданий — по UTC; портреты — процедурные заглушки;
гильдии/PvP/события не реализованы.
